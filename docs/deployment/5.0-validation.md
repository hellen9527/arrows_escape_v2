# Arrow Escape 5.0 validation

Replaces all 300 formal boards with fixed, reproducible long-path puzzles. C031 has 100 arrows, C060 has 136, and C300 has 233. Eight tutorials and the classic campaign retain their content. Previous v4 achievements are archived; current level and earned access survive the content replacement without assigning unearned v5 completions.

## Automated checks

- `npm run check`: 61 tests pass, all 300 engine-derived geometry/goal/key/budget audits pass, TypeScript and lint pass.
- `npm run reproduce:levels`: all 300 geometries, targets, keys and budgets match the published data exactly.
- Production Vinext/Cloudflare build and `git diff --check` pass. Existing build size/classification warnings remain; no deployment adapter or dependency changes.
- Independent read-only review checked runtime count floors, route encoding, generator dependencies and all 300 possible v4 current-level migrations, including reloaded access. No important correctness issue remained.
- Detailed metrics and limits are in `../level-design-300/v5-design-review.md` and `v5-audit.json`. The three audited removal policies are samples, not exhaustive human simulations.

## Production browser acceptance

Tested the built Worker on an isolated local origin, leaving the user's original-domain save untouched.

- Fresh experienced entry opens C031 with 100 arrows, 74 moves, two targets and three hearts.
- A real pointer click on an arrow head removes exactly that arrow. A board drag does not remove another arrow or cause failure. Overview, 2x, 3x and 5x zoom are usable for inspection and panning.
- Three blocked taps cause terminal heart failure. Retry restores the same 100-arrow board, 74 moves and three hearts.
- A full C031 target route was executed through the game's WebMCP tap action, using the actual UI handler. Seventy removals free both targets; 30 ordinary arrows remain and four moves are unused. The page records one independent completion, three stars, and opens only C032 in addition to existing chapter access. Reload retains the win and the same result summary.
- Chapter selection exposes all ten chapters through C300. Direct C271 entry shows the contextual two-key explanation. Its 219-arrow overview and 3x tracing view were inspected at 320x740; first-stage hint survives reload, and both subsequent hint stages work.
- 390x844 portrait, 320x740 narrow portrait and 844x390 landscape inspected. Measured page dimensions equal the latter two viewports, with no outer scroll overflow. Dense boards use internal zoom/panning. Viewport override reset afterward. This is desktop browser emulation, not a physical-phone touch test.

The first local preview process stalled; restarting the same production build on a fresh port served HTTP 200 in approximately 45 ms and enabled all acceptance above. No code change was needed for that local startup issue.

## Publishing and limits

Use the existing `hellen9527/arrows_escape_v2` main branch, Worker `arrows-escape-v2` and `https://arrows.fategenie.com/`. Final source SHA, deployment version and HTTPS asset identity are recorded in the workspace release-status file after publication. This document alone is not evidence of deployment.

Automated solvability, structural growth and successful browser operation do not establish player enjoyment or perceived difficulty. User sessions must determine whether the longer boards create satisfying tracing rather than repetitive work. The levels are authored/generated offline and fixed for every player; there is no runtime infinite generation or new backend.
