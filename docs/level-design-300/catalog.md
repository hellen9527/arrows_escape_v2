# 300 个正式关卡逐关设计卡

设计版本：2026-09-10 / D1。**以下 300 行都是原创内容设计，不是已实现棋盘，也不是竞品关卡复刻。**

共用规则、候选规模、预算、分流与验收见 [完整方案](</Users/leerainli/programs/games/docs/superpowers/specs/2026-09-10-arrow-300-design.md>)。每行与该阶段规范一起构成一张设计卡。

模式：清=清场；1星/2星/3星=移除全部星标即可完成；A/AB=一组/两组字母钥匙锁。B=舒缓、N=标准、H=挑战、X=综合验证，均为待测意图。P/Q/R 是星标，X/Y/Z 是关键普通箭头；“两支前置”必须都解除。“先”表示依赖顺序，不表示合法等价动作之间存在唯一正确次序。

所有行当前状态：**设计完成，待坐标布局、规则求解和真人校准**。体验验证点是要观察或证明的条件，未被预先判定通过。目标并列并不保证存在取舍；每关判断任务见核心关系。
