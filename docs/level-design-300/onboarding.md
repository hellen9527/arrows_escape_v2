# 新人引导与熟手规则补充

T01–T08 是 8 个独立于正式 300 关的教学设计。可跳过、可重看，不参与正式完成数。候选箭头数用于布局制作起点，未通过手机试玩前不视为难度标准。

初次入口显示「第一次玩」和「玩过类似」。前者完成 T01–T06 后进入 C001；T07/T08 分别在首次接触单钥匙/双钥匙内容时提供，也可提前查看。后者看简短差异卡后进入 C031；玩家可改选 C001 或其他阶段入口。跳过不授予星级或通关成绩。已有用户不重复弹出新手选择。

T 关无心数失败。教程允许撤销、重试和跳过；T06–T08 若预算耗尽则解释浪费的步骤并允许撤销恢复，不能停在不可操作的失败遮罩。该教程恢复行为需要实施时单独支持，不能直接沿用当前正式关的失败后禁用操作逻辑。

引导中的检查用于观察理解，不作为进入正式关的强制考试。玩家反复看同一答案不能被计为已经掌握；需要时提供新的同关系短布局，另记为练习而非增加正式关数量。

## 熟手差异卡

熟手不重学点击与直线离场。进入正式题目之前用可关闭的三条说明补充本作规则：

1. 星标关只需送走所有星标；普通箭头可以留下。
2. 每次成功移除消耗一步，撤销恢复这一步；碰撞另计心数。
3. 钥匙只打开同字母的锁，开锁后仍要检查出口；不同字母的先后由这关依赖决定。

差异卡带「看例子」入口，分别打开 T05/T06/T07/T08 对应片段。看完进入玩家选定关卡，不改掉其原断点。C031 不用钥匙，因此仅在第一次涉及钥匙或主动跳到有钥匙阶段时强调第三条。

## 同一题库的两类体验

新人通过短引导后，C001–C030 仍是完整正式题目，用目标回溯、共同阻挡与跨区关系练习迁移。熟手默认从 C031 开始就遇到双目标与相关性筛选；觉得起点不合适可直接换阶段，无需故意失败触发系统调整。

两类玩家的起点不同，规则和关卡版本一致。后续难度校准分别观察两组数据，不暗中给熟手减少步数或给新人替换一个更简单棋盘。需要辅助时由玩家主动选择，并如实标记辅助完成。
