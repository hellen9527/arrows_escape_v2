C031–060 旧盘大多平均 3.5–3.7 格。新 C031 的 96% 箭头至少转两次弯，约 77% 的物理阻挡边连接不同尖端方向。方向指的是箭头尖端方向；箭头身体拐弯后参与其他方向的阻挡。这些是结构事实，不能换算成真人难度分数。

300 关按十个章节的箭头区间分别为 44–100、100–136、134–153、149–168、166–180、177–191、187–201、198–212、208–222、219–233。十关区间的数量底线逐段上升；个别舒缓局可小幅回落。每五关一张全清关，共 60 张；其余 240 张保留星标目标与预算。1–90 无钥匙，91–120 单钥匙，121 起双钥匙。8 个独立练习不变。

## 借鉴什么，没有借鉴什么

- [Lessmore 官方游戏](https://play.google.com/store/apps/details?id=com.ecffri.arrows)：逐渐复杂的大量关卡、追踪箭头与全盘清场。没有取得其逐关数量、内部生成器、通关率或人群实验。
- [OutTheyGo 官方说明](https://www.outtheygo.com/)：明确展示百箭盘面，并说明 U 形、阶梯、长线和更深链条。它是一个直接同类产品的自述，不把其市场成熟度或改善效果当作已证实。
- [Pelánek 的难度研究](https://arxiv.org/abs/1403.7373)：数独里步骤复杂度与依赖结构共同影响预测；这里仅借鉴拆分结构与过程的测量思路，不复用数独难度系数。

百根数量、长度、折线比例、节奏与出口阈值都是本项目的设计假设，不是上述来源给出的行业标准。没有原样复刻他人关卡。

## 验证方式

实际游戏引擎重算坐标、阻挡、钥匙权限、目标闭包和步数。检查每关完整清场及目标通关，验证压缩路径无损与固定配方可重现，拒绝重叠、自挡、环路、缺失钥匙和重复盘面。

每关用三种合法选择顺序采样：低 ID 优先、高 ID 优先、优先释放较多箭头。开局、中局及 65–80% 进程分别记录可选目标路径与全盘可见出口比例；审计报告保留结果。它们不是人类玩家模拟，也不穷尽所有顺序。

纯清场是单调移除：任何合法移除都不破坏可解性。它的挑战来自辨认与追踪，不能声称有棋类那样的错误合法走法。星标预算提供需排除无关支路的取舍。完成 233 次点击本身不是思考深度；若试玩显示后半程是机械劳动，需要继续调整内容，不能用点击数证明好玩。

手机总览负责看全局，2×、3×、5× 用于追踪与准确点击；拖动不扣心。路径采用无损方向编码，避免把 300 张盘面的全部坐标 JSON 直接放进首包。v4 成绩归档并保留当前关号与已开放关卡的访问资格，新成绩单独记录；教程与经典进度保留。
