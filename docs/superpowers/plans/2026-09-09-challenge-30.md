**Goal:** Ship thirty original, more demanding arrow puzzles, meaningful three-heart failure, two hints per attempt, and safe mobile input while preserving the classic campaign.

**Architecture:** Add immutable authored/curated challenge data and metadata behind `makeLevel(id, campaign)`. Keep each campaign's versioned local save separate. The pure engine enforces terminal states; the existing UI gains campaign selection, hearts, failure and challenge feedback.

**Stack:** Existing React / TypeScript / Vinext / Cloudflare Worker, Node test runner and Playwright.
