# 箭头出逃：首版设计

用户已确认先做箭头类游戏，强调完整体验，商业化由后续运营验证。本轮交付可在手机及电脑浏览器运行的完整单机游戏和私有试玩地址。

## 体验

首屏直接进入棋盘。视觉以深蓝墨色、明亮蓝色和白色构成，箭头为连续折线，格点辅助观察，界面只保留关卡进度与必要操作。点击整条箭头均可操作；有阻挡时沿方向轻撞后返回并标记阻挡，不扣命、不强制重开。成功时箭头沿自身轨迹抽离，再飞出棋盘，配短音效。支持减少动画、关闭音效和中文/英文。

60 个关卡分五章，前三关用于教学，逐步增加密度、折弯和依赖深度。撤销、提示、重新开始、章节选关、星级记录、通关继续构成完整闭环。提示和误点影响本关星级，最低一星；撤销不清除已发生的提示与误点。进度、当前棋盘、偏好仅存本机，并容错损坏或不可用的存储。

## 规则与架构

棋盘使用离散格点，箭头由尾至头的正交相邻点组成，头部最后一段决定方向。只有前方射线没有其他箭头时才可离开。反向构造关卡，添加时每支箭头都有出口，反序移除保证可解。生成时排除自身挡住出口的形状。运行逻辑与 React/SVG 视图分开，可独立验证。

游戏状态转换负责点击、撤销、提示和计分，存档校验负责版本、编号和已移除箭头的合法顺序。音效由浏览器合成，不依赖外部素材。窄屏下控制按钮保持足够触控面积，棋盘可放大滚动以辅助精确点击。键盘可聚焦每支箭头并按 Enter/Space。

## 验收

程序逐关验证全部 60 关无重叠、路径连续、可解、内容不同；验证四向阻挡、误点、提示、撤销、计分、关卡解锁与损坏存档。执行类型检查及正式构建，确认本地 HTTP 响应和发布结果。浏览器实机交互测试仅在用户明确授权后进行，因此本轮不宣称已完成浏览器实机验收。

## 边界

本轮是完整浏览器单机版；原生商店包、广告、内购、账号、云存档及运营后台在确定发行方向后实施。所有图形、关卡算法和代码独立制作。
